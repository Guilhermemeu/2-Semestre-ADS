Questão 9 Difícil [CÓDIGO]

Analise o código T-SQL abaixo e assinale a alternativa que descreve corretamente o resultado produzido:

WITH TotalPorCliente AS (
    SELECT 
        c.ClienteID,
        c.Nome,
        SUM(p.ValorTotal) AS TotalGasto
    FROM Vendas.Clientes c
    INNER JOIN Vendas.Pedidos p ON c.ClienteID = p.ClienteID
    WHERE p.Status = 'Entregue'
    GROUP BY c.ClienteID, c.Nome
)
SELECT 
    ClienteID,
    Nome,
    TotalGasto,
    RANK() OVER (ORDER BY TotalGasto DESC) AS Ranking
FROM TotalPorCliente
ORDER BY Ranking;
  • A) Lista todos os clientes, inclusive os que nunca fizeram pedidos, com TotalGasto = 0.
  • B) Lista apenas os clientes com pedidos com status 'Entregue', mostrando o total gasto e um ranking decrescente por valor.
  • C) Retorna erro de sintaxe porque CTEs não podem ser usadas com funções de janela.
  • D) Retorna o total gasto por produto, não por cliente.
  • E) Ordena os clientes alfabeticamente pelo nome.

Questão 12 Difícil [CÓDIGO]

Escreva um comando T-SQL para criar uma tabela chamada Vendas.Produtos com as seguintes especificações:

  • Coluna ProdutoID: inteiro, auto-incremento começando em 1, chave primária.
  • Coluna Nome: texto Unicode de até 200 caracteres, obrigatório.
  • Coluna Preco: decimal com 10 dígitos totais e 2 decimais, obrigatório, com restrição de que deve ser maior ou igual a zero.
  • Coluna Categoria: texto de até 100 caracteres, obrigatório.
  • Coluna DataCadastro: data e hora, com valor padrão igual à data/hora atual do sistema.

Após criar a tabela, escreva um comando para inserir um produto chamado 'Notebook Pro', na categoria 'Eletrônicos', com preço 8500.00.
