  • Executar comandos básicos de diagnóstico de rede no Prompt de Comando (CMD) e no PowerShell.

📌 Introdução

Nesta aula prática, vamos explorar as ferramentas de linha de comando que todo profissional de TI deve conhecer. Tanto o CMD (Prompt de Comando) quanto o PowerShell oferecem utilitários para testar e diagnosticar redes. Embora muitos comandos sejam idênticos, o PowerShell traz recursos adicionais, como objetos e pipes.

Vamos começar com os comandos mais comuns e, em seguida, avançar para variações úteis. Execute cada comando no seu terminal e observe os resultados — a prática é essencial!

🧪 Comandos fundamentais

CMD / PS ping — testar conectividade

O ping envia pacotes ICMP para um destino e mede o tempo de resposta. É o primeiro comando para verificar se um host está ativo.

# Exemplo: pingar o gateway padrão (geralmente 192.168.1.1)
ping 192.168.1.1

# Pingar um servidor público (Google DNS)
ping 8.8.8.8

# No PowerShell, podemos usar -n para número de pacotes
ping -n 4 8.8.8.8

Saída típica: respostas com tempo em ms, TTL e estatísticas de perda.

CMD / PS ipconfig / ifconfig — informações de interface

Exibe a configuração de rede do adaptador: endereço IP, máscara de sub-rede, gateway padrão.

# CMD / PowerShell
ipconfig

# Mais detalhes (inclui MAC, DHCP, etc.)
ipconfig /all

# No PowerShell, também podemos usar Get-NetIPConfiguration (mais moderno)
Get-NetIPConfiguration | Select-Object InterfaceAlias, IPv4Address, IPv4DefaultGateway

CMD / PS tracert (ou traceroute) — rota até o destino

Mostra cada salto (roteador) entre seu computador e o destino, com os tempos de resposta.

# CMD / PowerShell (o comando é o mesmo)
tracert 8.8.8.8

# No PowerShell, também funciona com Test-NetConnection -TraceRoute
Test-NetConnection 8.8.8.8 -TraceRoute

CMD / PS nslookup — resolução de nomes DNS

Consulta servidores DNS para obter o endereço IP de um domínio (e vice-versa).

# Consultar o IP de um domínio
nslookup google.com

# Consultar um servidor DNS específico (ex: Cloudflare)
nslookup google.com 1.1.1.1

CMD arp — tabela de resolução de endereços

Exibe a tabela ARP (endereço IP ↔ MAC) da rede local.

# CMD / PowerShell
arp -a

CMD netstat — estatísticas e conexões ativas

Mostra portas abertas, conexões TCP/UDP e estatísticas de protocolo.

# CMD / PowerShell
netstat -an

# Exibir apenas conexões TCP estabelecidas
netstat -an | findstr ESTABLISHED   # no CMD
netstat -an | Select-String ESTABLISHED   # no PowerShell
💡 Dica: No PowerShell, você pode filtrar saídas com Select-String ou Where-Object, o que torna a análise mais flexível.

PowerShell Test-NetConnection — diagnóstico avançado

Substituto moderno do ping e tracert, com detecção de portas abertas.

# Testar conectividade e porta específica (ex: HTTP)
Test-NetConnection google.com -Port 80

# Testar conectividade com rota detalhada
Test-NetConnection 8.8.8.8 -TraceRoute

🔍 Roteiro prático — diagnóstico passo a passo

Vamos simular um diagnóstico de rede usando os comandos vistos. Abra o CMD ou PowerShell e execute na ordem:

  1. Verificar configuração: ipconfig /all — anote o IP, máscara e gateway.
  2. Testar gateway: ping <gateway> — se falhar, há problema no roteador ou cabo.
  3. Testar DNS externo: ping 8.8.8.8 — se falhar, problema de roteamento externo.
  4. Rastrear rota: tracert 8.8.8.8 — identifica onde os pacotes param.
  5. Resolver domínio: nslookup google.com — verifica se o DNS está funcionando.
🤔 Pare e Pense: Se o ping para 8.8.8.8 funciona, mas o ping google.com falha, qual é o provável problema? (Dica: pense no DNS).

🏢 Onde esses comandos são usados?

No dia a dia de um analista de suporte, administrador de redes ou desenvolvedor, esses comandos são a primeira linha de defesa para resolver problemas de conectividade. Eles ajudam a:

  • Diagnosticar lentidão em aplicações web.
  • Verificar se um servidor está acessível após uma implantação.
  • Validar configurações de firewall e roteamento.
  • Identificar ataques de negação de serviço (via netstat).

Saber interpretar a saída desses comandos é uma habilidade essencial para qualquer profissional de TI.

📖 Glossário de comandos

ping
Envia pacotes ICMP Echo Request para testar conectividade e medir latência.
ipconfig / ifconfig
Exibe a configuração de rede das interfaces (IP, máscara, gateway).
tracert / traceroute
Mostra a rota (saltos) percorrida pelos pacotes até o destino.
nslookup
Consulta servidores DNS para resolver nomes de domínio em IP e vice-versa.
arp
Gerencia a tabela de resolução de endereços IP para MAC (camada 2).
netstat
Exibe conexões ativas, portas abertas e estatísticas de rede.
Test-NetConnection
Comando do PowerShell que combina ping, traceroute e teste de porta.
