Instruções: Este gabarito contém as respostas corretas, justificativas técnicas detalhadas e, para as dissertativas, o padrão de resposta esperado (incluindo código quando aplicável).

Respostas – Questões Objetivas

Questão 1 Fácil

Alternativa correta: C) Modo de operação do canal

Justificativa:

O modo de operação do canal define a direcionalidade da transmissão: simplex (unidirecional), half-duplex (bidirecional alternado) e full-duplex (bidirecional simultâneo). As demais alternativas referem-se a outros critérios de classificação: serviço de transporte (circuito/pacote), modelo de comunicação (unicast, broadcast, multicast), topologia (disposição física) e abrangência (escala geográfica).

Questão 2 Fácil

Alternativa correta: C) Ponto único de falha no dispositivo central

Justificativa:

Na topologia em estrela, todos os dispositivos se conectam a um elemento central (switch, hub ou roteador). Se esse elemento falha, toda a rede fica inoperante. Embora haja outros custos e limitações, a principal desvantagem em termos de confiabilidade é o ponto único de falha.

Questão 3 Fácil

Alternativa correta: B) Broadcast

Justificativa:

Broadcast é o modelo de comunicação em que um emissor envia dados para todos os dispositivos no domínio de broadcast. Unicast é ponto a ponto; multicast é para um grupo; anycast e geocast são variações menos comuns em redes tradicionais.

Questão 4 Médio

Alternativa correta: C) Cada pacote é encaminhado independentemente, podendo seguir rotas diferentes.

Justificativa:

No modo datagrama da comutação de pacotes, não há reserva de recursos nem caminho fixo. Cada pacote contém endereço de destino e é roteado individualmente, podendo seguir caminhos distintos. As alternativas A e D descrevem comutação de circuitos; B descreve circuito virtual; E é incorreta, pois é usada em redes de dados (como a Internet).

Questão 5 Médio

Alternativa correta: C) MAN

Justificativa:

MAN (Metropolitan Area Network) é a rede que cobre uma área metropolitana, como uma cidade. PAN é pessoal (metros), LAN é local (até 1 km), WAN é ampla (países/continentes) e GAN é global.

Questão 6 Médio

Alternativa correta: C) Cliente1 e Cliente2 recebem a mensagem; Cliente3 não.

Justificativa:

O método receber verifica se o destino é "multicast" e se o nome do dispositivo está no grupo. Como Cliente1 e Cliente2 estão no grupo, eles recebem; Cliente3 não está no grupo, portanto ignora. Isso reproduz o comportamento esperado do multicast.

Questão 7 Médio

Alternativa correta: D) Malha

Justificativa:

A topologia em malha oferece múltiplos caminhos entre os nós, proporcionando alta redundância e tolerância a falhas. No entanto, exige mais cabos e equipamentos, além de gerenciamento mais complexo, o que aumenta o custo.

Questão 8 Difícil

Alternativa correta: C) É possível inferir a topologia física completa (cabos e switches) a partir desses comandos.

Justificativa:

Os comandos ip link, ip neigh e ip route fornecem informações sobre interfaces, vizinhos ARP e rotas, que ajudam a entender a topologia lógica (camadas 2 e 3), mas não revelam a topologia física detalhada (como cabos, switches físicos, disposição em rack). Para isso, seriam necessários protocolos como LLDP ou CDP. Portanto, a afirmação C é falsa.

Questão 9 Difícil

Alternativa correta: C) Multicast, enviando para um grupo de participantes inscritos.

Justificativa:

O multicast é o modelo mais eficiente para distribuir o mesmo fluxo a múltiplos receptores, pois o emissor envia uma única cópia e a rede se encarrega de replicá-la apenas para os ramos onde há receptores inscritos. Unicast geraria tráfego redundante; broadcast é desnecessário e pode sobrecarregar a rede; anycast não se aplica a esse cenário.

Questão 10 Difícil

Alternativa correta: C) Apenas III

Justificativa:

I é falsa: comutação de circuitos é menos eficiente em uso de enlaces que comutação de pacotes. II é falsa: half-duplex não permite transmissão simultânea; isso é full-duplex. III é correta: uma LAN pode abranger até cerca de 1 km (embora em alguns contextos possa ser maior, o padrão é essa ordem de grandeza). IV é falsa: barramento não é a mais utilizada; estrela é predominante. Portanto, apenas III é correta.

Questão 12 Difícil
Padrão de resposta esperado (código): 
class No:
    def __init__(self, nome):
        self.nome = nome
        self.proximo = None

    def __repr__(self):
        return self.nome

class Anel:
    def __init__(self):
        self.nos = []

    def adicionar_no(self, nome):
        novo = No(nome)
        if not self.nos:
            self.nos.append(novo)
            novo.proximo = novo   # aponta para si mesmo em anel de 1 nó
        else:
            # insere no final e ajusta o último para apontar para o novo, e o novo para o primeiro
            ultimo = self.nos[-1]
            ultimo.proximo = novo
            novo.proximo = self.nos[0]
            self.nos.append(novo)

    def enviar(self, origem_nome, destino_nome, mensagem):
        # encontra o nó de origem
        origem = None
        for no in self.nos:
            if no.nome == origem_nome:
                origem = no
                break
        if not origem:
            print(f"Origem {origem_nome} não encontrada.")
            return

        # percorre o anel a partir do próximo nó
        atual = origem.proximo
        caminho = [origem.nome]
        while atual != origem:
            caminho.append(atual.nome)
            if atual.nome == destino_nome:
                print(" -> ".join(caminho) + f" : {mensagem}")
                return
            atual = atual.proximo
        print(f"Destino {destino_nome} não alcançado (anel percorrido).")

# Exemplo de uso:
anel = Anel()
for nome in ["N1", "N2", "N3", "N4"]:
    anel.adicionar_no(nome)

anel.enviar("N1", "N3", "Olá, N3!")
# Saída esperada: N1 -> N2 -> N3 : Olá, N3!

Explicação: A classe Anel mantém uma lista de nós, cada um com referência ao próximo. O método enviar percorre o anel a partir da origem, acumulando o caminho, até encontrar o destino ou retornar à origem.

Questão 13 Médio
Padrão de resposta esperado:

Erro identificado: O código exibe "Descartando para ..." para todos os dispositivos que não são o destino, o que é desnecessário e polui a saída. Além disso, se o destino não for encontrado, nenhuma mensagem é entregue (o que é correto), mas a mensagem de "Descartando" pode ser confusa, pois sugere que a mensagem foi descartada mesmo quando o dispositivo não era o destino — o que não é um erro, mas sim o comportamento normal do unicast.

Correção: Remover o else que imprime "Descartando", pois em unicast a mensagem deve ser enviada apenas ao destino, e os demais dispositivos simplesmente não a recebem. O código revisado:

def enviar_unicast(rede, origem, destino, mensagem):
    for dispositivo in rede.dispositivos:
        if dispositivo.nome == destino:
            dispositivo.receber(mensagem, origem)
            return   # para após encontrar o destino
    print(f"Destino {destino} não encontrado.")

Dessa forma, a mensagem é entregue apenas ao destinatário e não há saídas indesejadas.

Questão 14 Fácil
Padrão de resposta esperado:

A topologia física refere-se à disposição real dos cabos, dispositivos e equipamentos (como a forma como os switches estão conectados fisicamente). A topologia lógica descreve como os dados fluem na rede, ou seja, o caminho que as informações percorrem logicamente, independente da disposição física.

Exemplo: Em uma rede com switches interconectados em estrela (fisicamente), a topologia lógica pode ser um barramento se todos os dispositivos compartilharem o mesmo domínio de colisão (em redes antigas com hubs). Atualmente, com switches, a topologia lógica é também em estrela, mas VLANs podem criar topologias lógicas diferentes da física.

Questão 15 Difícil
Padrão de resposta esperado:

Topologia interna dos prédios (LAN): Estrela com switches, pois oferece gerenciamento centralizado, fácil expansão e isola falhas. Cada andar pode ter um switch, interconectados em árvore ou cascata.

Topologia entre prédios (campus): Malha parcial ou anel com redundância (ex: dois caminhos distintos entre os prédios) para garantir alta disponibilidade. Pode-se usar fibra óptica e protocolos de roteamento dinâmico.

Modo de operação: Full-duplex em todas as conexões, pois permite transmissão simultânea, maximizando a utilização do enlace e reduzindo colisões (comum em Ethernet com switches).

Modelo de comunicação: Avisos institucionais em texto podem usar broadcast (se forem para todos) ou unicast (se personalizados). Aulas ao vivo em vídeo devem usar multicast para otimizar o tráfego, evitando cópias individuais para cada receptor.

Justificativa dos critérios: A escolha da topologia leva em conta a abrangência (LAN e MAN), a confiabilidade (malha), o modo de operação (full-duplex) e o modelo de comunicação adequado a cada tipo de tráfego.
